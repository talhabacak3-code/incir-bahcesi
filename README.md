# İncir Bahçesi 🌿

Anadolu'nun bereketli topraklarından doğal yöresel ürünler satan **İncir Bahçesi** firmasının tanıtım web sitesi (Afyonkarahisar merkezli).

Saf **HTML + CSS + JavaScript** ile geliştirilmiştir; harici bağımlılık (CDN, framework) yoktur — çevrimdışı da düzgün çalışır.

## Özellikler
- Tek sayfa, kaydırmalı modern tasarım
- Vizyon / Misyon / Değerler bölümü
- Öne çıkan ürünler: **Ceviz, Zeytinyağı, Haşhaş Ezmesi**
- Aranabilir tüm ürünler bölümü (23 ürün)
- Her ürün için **WhatsApp ile sipariş** butonu
- İletişim: adres + Google harita, telefon, Instagram, WhatsApp
- Mobil uyumlu (responsive) ve erişilebilir
- Inline SVG ikonlar (her zaman çalışır)

## Kurulum
Ek bir araç gerektirmez. `index.html` dosyasını tarayıcıda açmanız yeterli.

## Dosya yapısı
```
├─ index.html        # Tüm bölümler
├─ css/style.css     # Tema ve stiller
├─ js/main.js        # Ürünler, arama, menü, WhatsApp linkleri
└─ assets/
   └─ logo.png       # Firma logosu
```
